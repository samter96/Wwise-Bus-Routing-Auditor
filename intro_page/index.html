Two Scan Modes

이름 기준과 Work Unit 기준을 분리해서 검사

같은 Sound라도 “파일명은 UI인데 버스는 SFX”인 경우와 “UI Work Unit에 있는데 버스가 어긋난” 경우를 따로 볼 수 있습니다.

SCAN 01

에셋 이름 키워드 검사

Sound 이름에 포함된 토큰을 기준으로 현재 OutputBus 이름이 기대 키워드를 포함하는지 확인합니다.

SCAN 02

Work Unit / 경로 검사

Sound가 속한 Work Unit 이름, Work Unit 전체 경로, 상위 경로를 기준으로 라우팅 위반을 찾습니다.

ACTION

선택 항목 일괄 재라우팅

위반 목록에서 선택한 Sound들의 OutputBus를 지정 버스로 한 번에 변경하고, 결과는 CSV로 내보낼 수 있습니다.

Rule Builder

룰은 간단하게, 예외는 OR 조건으로

UI, Music, AMB, VO 같은 기준 키워드를 룰로 저장하고, 하나의 Sound가 여러 룰에 걸리는 경우에는 하나라도 만족하면 통과하도록 판정합니다.

Install

Wwise Tools 메뉴에서 바로 실행

설치 후 Wwise에서 Tools > Bus Routing Auditor를 실행합니다. WAAPI는 Project > User Preferences > Enable Wwise Authoring API에서 켜야 합니다.

저장소 받기

git clone 또는 GitHub의 Download ZIP으로 프로젝트를 내려받습니다.

패키지 설치

install.bat을 실행해 가상환경과 waapi-client를 준비합니다.

Wwise Add-on 등록

install_addon.bat을 실행하면 Wwise Commands Add-on JSON이 생성됩니다.

툴 실행

Wwise를 재시작하거나 Command Add-ons를 Reload한 뒤 Tools 메뉴에서 실행합니다.
